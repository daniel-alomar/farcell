# Rol opcional: coordinador de coneixement

Entrada: ruta de volta, fonts autoritzades, objectiu, idioma i límit de lot.
Llegeix `../skills/farcell/SKILL.md` respecte d'aquest fitxer.
Planifica el lot i integra les notes com a únic escriptor, respectant el
bloqueig, les edicions humanes i l'inventari. Si es demana una revisió, passa
al revisor les notes canviades, originals i abast; integra només incidències
verificades. Sortida: canvis, evidències, pendents i resultats de comprovació.
Aquest rol es pot assumir en la sessió principal; no implica crear un subagent.
