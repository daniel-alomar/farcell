# Context del producte

Objectiu: convertir corpus heterogenis en coneixement navegable i traçable.
Públic: persones que volen entendre i consultar una col·lecció de fonts.
La llengua i categories són decisions de cada volta, no d'aquest repositori.

La skill és autocontinguda. Els rols opcionals separen integració i revisió;
només un escriptor modifica la volta. L'eina d'estat valida canvis i destins,
no el significat de les notes. Manteniment sota demanda per defecte.

Repositori: https://github.com/daniel-alomar/farcell.
Els exemples són opcionals i no s’injecten al context de les voltes.

Python és un auxiliar opcional. El mode manual conserva traçabilitat i
revisió, amb menys detecció automàtica de canvis.
